# Apple M5 Pro — conv1d / conv2d / conv3d

- Chip: Apple M5 Pro
- macOS: 27.0
- RAM: 24 GB
- `python bench/bench_conv.py --dtype {bf16,fp32} --batches 1,2,4,8,16,32 --cool 0.2`
  (every shape swept over batch 1/2/4/8/16/32; torch/metalblas trials interleaved
  so both sides sample the same thermal window)

Speedup is `metalblas.conv*` vs `torch.nn.functional.conv*` on MPS. Shapes are
`N x C x spatial -> O` (batch, in-channels, spatial dims, out-channels); params
are kernel `k`, padding `p`, stride `s`, dilation `d`, groups `g` (omitted when
1/0), `CL` = channels_last input.

Routing note: the autotuner keeps a shape on metalBLAS kernels only when they
beat MPSGraph by >6% on the real operands; everything else routes to torch. A
torch-routed shape therefore runs torch itself (+ ~2us dispatch) and is parity
by construction - single-run rows at 0.95-0.98x are bench noise (torch-vs-torch
measures the same spread), not real losses.

## Summary

| op | bf16 | fp32 |
| --- | --- | --- |
| conv2d (NCHW) | median **1.68x** (max 6.4x) | median **1.98x** (max 9.6x) |
| conv2d (channels_last) | median **1.25x** | median **1.71x** |
| conv1d | median **1.33x** (Mamba depthwise **~5x**) | median **2.73x** |
| conv3d | median **10.9x** | median **8.1x** |

Notes:

- Batch scaling: small batches (1-4) lean hardest our way (torch's per-call
  overhead dominates there); large batches converge to steady-state kernel
  rates, where near-ties route to torch as the parity floor.
- conv3d's outsized wins come from MPSGraph's conv3d running at ~1.5-2 TFLOPS
  at every batch size; the metalBLAS depth-accumulate kernel runs it at
  matmul-class rates.
- Stride-1 conv1d rides a shift-GEMM kernel (k accumulated column-shifted
  GEMMs on raw NCL memory, no layout transforms): wav/TCN-class shapes run
  1.05-1.20x where the transposed path lost.
- Depthwise (`groups == C`) rides a direct bandwidth-bound kernel; its lead
  grows with batch (torch falls off a cliff at b=32: ~6.5x bf16 / ~9.6x fp32).
- fp32 uses the tensor unit's relaxed (TF32-style) mode, same as
  `metalblas.matmul`.
